# 联合优化约束整合稿

本目录保存用户提供的《GSdeploy改3_任务数量协同与短窗口实机实验版》的建模整合稿。

- `GSdeploy改3_联合优化约束整合版.docx`：可编辑 Word 文档。
- `render/GSdeploy改3_联合优化约束整合版.pdf`：排版预览，全文 25 页，修改位于第 7—8 页。
- `merged-section.zh.txt`：整合小节的文本导出。
- `merge_constraints.py`：由原附件生成文档并检查修改范围的脚本；脚本中的附件路径需在其他环境中调整。
- `revision-audit.json`：输入、输出 SHA-256 与修改范围记录。
- `render-validation.json`：公式分组、表格与版面检查记录。

“联合优化约束”统一包含驻留与副本、显存、路由与能力、共享覆盖、请求分配及共享工作与独立 FIFO 关系。修正驻留和副本的关联为 `x_m <= n_m <= N_m_max * x_m`，保留式（7）至（7d）及后文引用。独立 FIFO 表达基准计算关系；完整共驻时延与能耗仍由原模拟器计算，效用分解用于机制分析。

原附件 SHA-256：`78759ea7fd87f6751362dc312a5fa6d779f9e98d466e58981b70b44dd828f1f8`。修改仅涉及 DOCX 的 `word/document.xml` 中对应建模小节，实验与结果保持原附件内容。

本目录的上述七个交付文件由根目录 `.gitignore` 逐项放行，可直接用普通 `git add` 跟踪；原始实验输出、日志和临时渲染图片仍被忽略。根目录 `.gitattributes` 将 Word 和 PDF 声明为二进制文件，保留原始字节。
