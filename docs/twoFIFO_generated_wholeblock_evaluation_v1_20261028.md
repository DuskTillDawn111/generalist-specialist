# Generated whole-block conditional training evaluation v1

The isolated runner `twoFIFO_generated_wholeblock_evaluation_v1.py` connects the
new native v3 intake, phase12 fit v2, joint law v4, immutable settled history,
v5_2 forecast and finite ensemble. It never invokes a model or GPU. All twelve
complete native attempts, all 546 measured offers, 216 history-only priming rows
and three whole four-shard blocks must authenticate before numerical fitting or
raw generation. Partial intake returns WAITING without extraction, fitting or
law compilation. Legacy v2 capture evidence remains on HOLD.

`prepare(campaign, scoring_plan, quality, output)` accepts explicit public score
and quality JSON paths, fixes their receipts and the full source closure, and
writes a design before numerical fitting. It validates the unchanged original
six-term normalization, ten-second window and 3600-second startup amortization.
No workload, quality value, scale or resource estimate is inferred from heldout
observations. The design is closed and audits exact block identities, source
receipts, public scoring inputs and its complete predefined draw scheme.

The scheme has four equal strata within each equally weighted training block.
For each public `(owner, task, exact input, arrival ordinal)` slot, a fixed public
salt and SHA256 determine a rotation of midpoint quantiles 1/8, 3/8, 5/8 and 7/8.
Request/case/raw IDs and observed forecast errors do not select donors. One common
block and finite stratum slot are shared across inputs. This is explicit finite
quadrature with public slot dependence, not independently sampled request draws,
an identified latent split distribution or a calibrated long-term risk law. A
leaveout forecast has two donor blocks and eight worlds, each of weight 1/8.
Every chosen entry/forward/OCR/tail, query outcome, READY and protocol vector moves
jointly with its paired transport feasible set.

`run(design, reviews, output)` first computes the actual complete full/fold
numerical certificates using the existing pure solver. Full/fold joint laws retain
the existing full twelve-attempt numerical/OCR-support gates. The full law is
saved for review and never generates heldout forecasts. Each folded law excludes
all four heldout attempts and uses its own training-fold coefficients and donor
vectors. Failed qualification produces explicit UNKNOWN worlds for every case;
it does not select successful folds, drop columns, change the design or fit a
partial cohort.

For a heldout case, generation receives only its public frozen arrivals, the known
case epoch, the captured immutable prior-history snapshot and the training-fold
law. The snapshot seed retains real worker lifetimes, past protocol station clocks
and explicit tracked relative producer offsets. Unsettled/missing past is UNKNOWN.
This is conditional forecasting after observing the case origin and past; it does
not predict startup/priming, orchestration gaps or the entire attempt calendar.
Heldout future macro work, stop lengths, BEGIN shapes, READY, query outcomes and
completion labels never enter the case-generation interface.

Scientifically missing compilation evidence becomes the ensemble's exact typed
`UnknownForecastInputs`, retaining the original world, weight and all public
requests. Programming/contract errors propagate. Non-singleton transport START
sets remain UNKNOWN with exact bounds. No missing line or worker continuation is
set to zero, and unknown probability is never renormalized. Resources are omitted
in this runner, so M/E and full U retain their original UNKNOWN behavior.

Every case prediction is fsynced before that case's parent RESULT-reader labels
are extracted for its evaluation. Earlier intake and full/fold numerical review
already access heldout response labels; these labels remain outside the case
generation interface. Labels use the unchanged six-term arithmetic and fixed
10-second measurement/60-second drain. The score's Q uses frozen training quality
expectations, not measured native outcome quality; actual native quality remains
unvalidated. This supports conditional queue diagnostics, not final utility
evidence. Complete per-request/world errors,
known-incomplete mass, unknown mass and full case denominators remain in reports.
A global equal-block MAE is supplied only if every offered request has a supported
point expectation in all three blocks. Conditional subset errors are labeled.
The expected world P95 is explicitly not the P95 of a mixture. Each full law is
saved, and compact case predictions retain all request/world probabilities and
clocks plus a deterministic hash of each full generated trace, avoiding duplicated
large timelines.

Twelve author CPU tests cover actual folded-law compilation into v5_2, all eight
predefined worlds, absent donors retaining half probability, missing/unsettled
past retaining full UNKNOWN probability, identity-invariant donor choice,
heldout future RESULT/READY/query poisoning, explicit errors, original label
arithmetic, durable prediction before case evaluation label extraction, immutable score/quality/draw
design, the incomplete twelve-attempt gate and full 150-case/546-request/1200-world
orchestration with an unqualified fit. The latter is an injected CPU fixture,
not native training qualification. No actual native fit or generated accuracy
claim has been made while the campaign remains incomplete.
