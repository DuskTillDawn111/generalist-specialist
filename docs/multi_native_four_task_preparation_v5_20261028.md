## Minimal implementation after the source window

The source-bound design packet is
`artifacts/predictor-multi-native-composite-design-v5-20261028-final01/design.json`.
A new composite schema should bind each original DAG, host, lifecycle and quality
artifact and its original context. A dispatcher should select original providers
by family/task and retain the source binding for every alias/task/input profile.
Each result should expose both its original component context and the new
composite identity. No source model or full-context ID should be rewritten.

The new gate must explicitly select collector-invariance, profiler-to-natural
transfer, partial host identification, pooling, numerical-duration and provisional
hypotheses. Duplicate routes, unresolved topology, missing source receipts,
unsupported exact inputs and numerical UNKNOWN must fail. Existing pilot gate
sources remain untouched. Joint energy/memory/startup/generation and actual
four-task target readiness still require their own source-bound checks.

No new GPU workload, frozen protocol or four-task validation is created here.
