# 总效用 v3：分组评分与现有数据离线复核

2026-11-05。本阶段已实现独立评分接口、逐请求交付质量诊断与固定敏感性分析。使用已有六次确认、576 个请求；新增 GPU episode、预测器调用、训练、搜索运行均为 **0**。预测器工作已收尾，不再扩展验证。

结果：默认 v3 和全部 108 组设置都选纯专用路由；预测选择的两轮 regret 和平均 regret 都为 0。这是当前三个候选的回顾性比较，不是 v3 的新独立确认，也不是重新搜索得到的全域最优。新版数值与旧版数值不可直接解释为性能提升。

## 1. 已落地的公式和接口

[实现](../gsdeploy/utility_tradeoffs.py)提供 `episode_metrics`、`score_terms` 和 `compare_panel`；[CLI](../experiments/review_scoped_utility.py)负责冻结来源核对、旧结果复现与新版评估；[配置](../configs/utility_tradeoffs_v3_20261105.json)固定本次范围。

默认 profile 为 `four_groups_v3`：

```text
S = (T + L + P)/3
U_v3 = -(Q + S + M + E)/4

Q = Σ alpha_t · (native_loss_t - best_t)/(worst_t - best_t)
T = 1 - timely_successful_requests/offered_requests
L = Σ alpha_t · mean_e2e_t/latency_scale_t
P = Σ alpha_t · p95_e2e_t/latency_scale_t
M = raw_owned_sampled_peak_mib/memory_budget_mib
E = full_GPU_episode_joules/fixed_energy_scale_joules
```

|方案|Q|T|L|P|M|E|
|---|---:|---:|---:|---:|---:|---:|
|原六项等权 `six_equal_v2`|1/6|1/6|1/6|1/6|1/6|1/6|
|五组对照 `five_groups`|0.2|0.2|0.1|0.1|0.2|0.2|
|默认四组 `four_groups_v3`|0.25|1/12|1/12|1/12|0.25|0.25|

服务维度的名义系数由 1/2 降至 1/4，质量、显存、能耗各占 1/4。四组等权是明确的偏好选择，不是论文证明的最优权重。T/L/P 仍有相关性；L/P 仍无上界，因此服务实际贡献可以远超 25%。分组控制合计系数，不等于消除了全部重复计权或限制了尾延迟惩罚。

所有质量锚点、显存预算 49140 MiB、安全系数 1.110854、rho≤0.8 保持原值。Q 不截断到 [0,1]；超出开发锚点的质量保留真实差异。可行性独立于效用：只从预测可行候选中选择，若所选者实测不可行，则对应 regret 未定义，不能事后换一个赢家掩盖失败。未加入绝对质量门槛。

### deadline 与连续延迟尺度分离

默认 deadline 仍为参考 solo 平均时延的 2 倍；固定 `latency_scale_ms` 等于原 v2 deadline。只把实验 SLO 倍数改为 1/2/4/8 时，改变 T 与及时交付诊断，**L/P 的分母不变**。这些是实验 SLO，尚无证据表明它们就是业务可接受等待时间。

### 正确且按时交付

text/QA 和 image 增加逐请求联合指标：

```text
correct_and_timely_fraction = count(correct AND e2e <= deadline)/offered
```

它不能用平均正确率乘按时率替代。测试构造了 Q/T/时延分布完全相同、联合交付比例分别为 50% 和 0% 的反例。

OCR/ASR 继续用总编辑错误数除以总参考字符/词数；允许 CER/WER>1，不做逐请求错误率的简单平均。其联合价值明确输出 `null` 和原因，未把 `1-WER` 伪装成正确概率。当前联合指标为诊断项，尚未作为跨任务第七项加入 U；这是保留的设计限制。

接口要求完整且全部成功的 offered cohort；重复/缺失请求、缺任务、非有限数值、错误归一化尺度或缺项均拒绝进入评分。它尚不适用于丢弃、拒绝或容错策略的效用比较。

### 能耗尺度与真实能量

保留 `182965.79214663396 J` 为固定偏好尺度，明确它来自旧 1800 秒协议与不同负载，**不是当前约 649 秒 offered 窗口的匹配基线**。不按窗口长度假设启动能耗可线性缩放，也不事后用赢家能量重设正式分母。

报告同时输出完整 GPU episode J、J/offered、五个原始能量分段，以及同轮同 offered 输入/到达条件下相对纯专用的实测节能比例。能量边界为 startup_begin 至 observation_end，包含加载、priming、formal/drain 与观测尾部，不包含窗后退出以及主机 CPU/RAM。`formal_window_through_full_drain` 只是已有时间分段，不能称为稳态能量。

## 2. 实际比较结果

|候选|原 v2 平均实测 U|默认 v3 平均实测 U|默认 v3 平均预测 U|
|---|---:|---:|---:|
|candidate-1：纯专用路由|−0.631654|**−0.514308**|−0.513272|
|candidate-2：网格外对照|−1.267688|−0.899425|−0.925943|
|candidate-3：各任务 G2 分流 50%|−5.797282|−3.182805|−3.273969|

所有方案都是五模型全部驻留、各一副本；“纯专用”仅指路由，G2 仍占驻留资源。candidate-2 的 G2 份额为 ASR 25%、image 100%、OCR 0%、text 100%，是已观察的网格外对照，不是 BO 胜者。

默认 v3 中 candidate-2 相对纯专用两轮 ΔU 分别为 −0.231364、−0.538869；candidate-3 为 −1.857191、−3.479803。结果 JSON 提供所有分项贡献差，避免仅凭绝对分项大小判断谁决定了排名。平均差距中，candidate-2 的 Q/L/P 贡献分别为 −0.092175/−0.087661/−0.181615；candidate-3 的 P 差为 −2.047413，尾延迟仍是其主要劣势。

有限敏感性网格为：3 权重方案 × 4 deadline 倍数 × 3 能耗尺度因子 × 3 质量跨度因子 = **108**。后两者均为 0.5/1/2，质量最好锚点保持固定，所有任务共享跨度因子。这是偏好/尺度扰动，不是锚点统计置信区间，也未覆盖所有逐任务偏好。

108 组预测与实测平均赢家均为 candidate-1，平均和每轮 regret 最大值均为 0，无未定义 regret。对每个 deadline 倍数，两轮平均的 Q/T/L/P/M/E 都是 candidate-1 严格优于另外两个候选。因此在这些固定分项上，任意非负且和为 1 的六项权重都不会改变平均赢家；删掉某一项也不会改变这一点。该性质不延伸到新增指标、逐任务重新加权或未测候选。

### 总分领先不能替代交付质量

默认 deadline 下，以下分母均为每任务两轮共 48 个请求。重复历史并未增加独立输入覆盖，因此这些是本面板计数。

|候选|text 正确且按时|image 正确且按时|text 按时|image 按时|OCR 按时|ASR 按时|
|---|---:|---:|---:|---:|---:|---:|
|纯专用|22/48（45.83%）|21/48（43.75%）|33/48|27/48|24/48|40/48|
|网格外|15/48（31.25%）|1/48（2.08%）|24/48|4/48|28/48|33/48|
|G2 50%|19/48（39.58%）|9/48（18.75%）|25/48|15/48|16/48|24/48|

尤其纯专用第二轮 OCR 为 **0/24 按时**，image 为 **3/24 按时**；第一轮对应为 24/24 和 24/24。纯专用两轮合计仅 124/192 按时（64.58%）。它是当前候选中总效用最高者，不能据此宣布达到了服务 SLO；OCR 按时数这一单项甚至由网格外对照更好。这也说明分组总分之外仍须保留每任务、每轮明细，不据这些问题重新启动底层预测器排查。

### 能耗对照

|候选|第一轮完整 GPU J|第二轮完整 GPU J|相对同轮纯专用能耗增加|
|---|---:|---:|---:|
|纯专用|83,237.12|64,987.30|基准|
|网格外|87,121.25|70,729.94|4.67% / 8.84%|
|G2 50%|125,352.70|117,793.66|50.60% / 81.26%|

这些描述性对照不是完整机器节能结论；两轮差异也说明应配对比较，不能拿不同到达历史交叉相除。

质量跨度的隐含权重仍存在。默认 v3 中原生损失增加 0.01，对 U 的变化约为 text −0.002500、image −0.002667、OCR −0.008003、ASR −0.017422。四组改动没有消除开发锚点的小样本不确定性，不把它宣传为已解决。
