新增 `artifacts/system-evidence-stage-20261018`，已通过 **200 项 CPU 回归、零跳过**，未合入原仓库，也未改变上述已冻结候选实验包。这个隔离版本保存 worker PID、READY 身份及 priming 后/排空后两次完整 NVML 快照；显存评分使用已知 worker 的驻留量，整卡采样峰值另作安全检查。缺失 PID/显存、瞬时外部进程、功率上限改变或遥测错误均不能生成完整资源证明。
