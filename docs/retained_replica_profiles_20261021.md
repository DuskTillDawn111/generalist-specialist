# 保留模型多副本资源画像

用户在完成 OCR 和百川合成分支移除后授权执行。证据目录：
`artifacts/retained-replica-profiles-20261021/`。

已完成：16/16组合，61档完整三轮画像、15712个正式请求均有效。
6档真实边界失败保留：百川图像4副本实际CUDA OOM，百川QA3、OCR4、
Qwen图像5、QA5、OCR4副本触发采样峰安全预算限制。
最初百川三个非QA任务误用了旧校准协议，因新数据集名称绑定被拒绝；
已在独立冻结`protocol-binding-correction-v2/`包使用原新数据集协议重跑，
原失败记录保留。两个队列均完成，GPU已释放。

最终合并结果为`combined-report.zh.md`、`combined-summary.json`、
`combined-summary.csv`，合并核验状态`COMPLETE_VERIFIED_RESOURCE_GRID`。
该状态仅指本轮有限资源网格已完成，含按预定规则排除、提前停止和失败证据。

运行状态以该目录的 `state.json` 为准，`report.md` 和 `summary.json`
在每档完成后更新。冻结方案为 `release.json`，原始请求、启动信息、
预热信息、50 ms NVML 采样分别在 `runs/<模型-任务-n副本>/`。

七个保留模型形成十六个模型与任务组合：三个通用模型各四任务，
ChatQA、SigLIP2、PP-OCRv6、Granite 各一个任务。执行配置逐任务读取
此前已验证的 worker；百川统一替换为已经完成四任务等价验证的去语音合成版本。
实际 Qwen 保留 worker 配置为 bitsandbytes **4 bit**，不可依据历史文字
描述写成 8 bit。模型及推理解码没有在本次实验中优化。

每个副本使用独立进程、同一 GPU、完整模型、batch=1。各进程只保留
一个在途请求，测饱和闭环；因此结果不建立开环容量或外部排队延迟 SLO。
图像从原400输入按像素数取64个，QA从原80输入按上下文与问题字符数
取32个，OCR从200页按像素数取32个，ASR从500条按完整时长取32个。
采用包含最小与最大输入的等距分位位置，按输入属性选样，不看模型输出。
输入中移除答案和标签；原参考仅在独立离线输出核对脚本中读取。
每一档使用同一个输入集合，三个随机顺序轮次，每轮覆盖全部输入且至少30秒。
快速任务因此会重复请求；各档实际请求数保留，延迟与能耗不删失败请求。

各模型依次测1、2、3、4、5副本；PP-OCR为1、2、3、4、6、8副本。
线性驻留预测超过显存预算会保守排除，实际加载、预热、运行失败及实际
采样峰超过安全预算也会停止更高档。预算49140 MiB，安全系数1.110854。
连续两档吞吐增益小于5%停止更高档。这个有限网格不证明最大可行副本数。
每档都有实际并发测量，驻留线性估算只用于排除，不冒充并发实测。

能耗主口径为完整 GPU 板卡采样功率积分，累计能量计数器另存作诊断，
包含板卡空闲功耗，不计 CPU 能耗。进程显存与整卡显存分开；加载峰、
测量峰分开。NVML采样不能排除采样间更短显存尖峰。

`scripts/audit_retained_replica_outputs_20261021.py` 离线逐请求核对单副本、
多副本及原实验输出，结果为 `output-equivalence.json`。

本轮是独立资源画像。它不恢复 QA 训练或门槛调整，不建立整池准入，
也不证明全数据最坏显存、混合模型共驻留、任务混合或开放请求率稳定性。
旧正式准入守卫未改变；冻结原实验源码和结果未改写。

输出审计：61个完成档位中，百川、Qwen与四专用所有正式请求均与原实验
对应输入一致；Mini部分重复请求出现原始输出或token数波动。相对原实验
15次请求有字段差异，相对对应n1基准11次。`output-equivalence.json`保留
具体输入、字段及原始输出文件SHA，不以“生成有效”代替质量等价。
