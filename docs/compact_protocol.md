# 四任务固定协议

`configs/compact_protocol.json` 固定输入、解码、评分、质量准入和效用参考；
`configs/compact_execution.json` 固定七个候选的实际加载配置。
CPU 检查不加载检查点，GPU 兼容性和模型指标仍待测量。

## 输入与原生执行

| 任务 | 正式独立质量输入 | 原生专用路径 | 固定规则 |
|---|---:|---|---|
| 上下文 QA | 500 | UnifiedQA T5 | 完整问题和段落；最多 512 个输入 token 含 EOS；超长报错；输出最多 128 token |
| 图像分类 | 400 | SigLIP get_image_features/get_text_features | 200 个来源类各 2 图；所有模型面对完整 1000 标签；SigLIP 缓存全部标签特征 |
| 整页 OCR | 200 | DeepSeek 原生 infer | RGB/EXIF 规范化、最长边 2048、LANCZOS、无损 PNG；整页不裁剪；输出最多 8192 token |
| ASR | 500 | Whisper 原生 generate | 完整单声道 16kHz、4–30 秒；英语转写；无翻译/说话人/时间戳；最多 440 新 token |

三个通用均覆盖全部四任务，共 12 条通用路径，加 4 条专用路径。
原生提示格式可以不同，底层输入、参考答案、标签集合与评分一致。
Qwen 固定图像范围 3136–1003520 像素，最多约 1280 个视觉 token；整页先统一预处理。
Qwen 通过原生 `audio_kwargs.max_length=480000` 将语音补齐预算固定为 30 秒，
`truncation=False`，完整保留本研究所有短于 30 秒的音频；有效语音由 mask 标记。MiniCPM 显式禁止静默截断，完整输入超出预算报错。
QA 独立集已按原生 T5 tokenizer 核验，可完整容纳，不使用滑窗择优答案。

Qwen 关闭 Talker，保留文字/图像/语音理解；MiniCPM 官方 GPTQ 加载器需要的 TTS 模块
如实际常驻就计入显存，不假定关闭输出意味着模块已经移除。
Phi 只对语言线性层使用 NF4；DeepSeek INT8 保留视觉与投影模块；T5 使用 INT8。
这些加载实现仍需 GPU 检验，不继承旧 BF16 质量准入。

执行器在 `gsdeploy/backends/compact_native.py`，CPU 前处理审计在
`gsdeploy/profiling/preprocessing.py`。MiniCPM/DeepSeek 的 CPU 检查执行固定原生源代码的
前处理部分，止于生成边界，不构造神经网络或加载权重。

## 输出与评分

生成模型必须记录真实生成 token、终止 token 和 EOS；字符串看起来完整不能替代 EOS。
未知结束、达到长度上限、无效分类标签、空转写都算失败。失败请求保留在质量分母。
SigLIP 要求完整 1000 类有限分数，输出必须等于 argmax。
原始输出保留，参考答案仅在推理结束后进入评分。

| 任务 | 主指标 | 最低门槛 | 评分规则 |
|---|---|---|---|
| QA | EM | EM≥0.50，F1≥0.60；可回答/不可回答 EM 均≥0.50 | SQuAD 式大小写、英文标点、冠词、空白归一化；多参考取最大 |
| 图像 | Top-1 | ≥0.25 | WordNet ID 精确匹配；不缩小为 200 类预测 |
| OCR | corpus CER | ≤0.20 | HTML 可见文字、Markdown 表格去结构；NFKC、casefold、合并空白；保留标点/价格/逗号/负号 |
| ASR | corpus WER | ≤0.15 | 英语词法归一化、保留词内撇号、不展开数字；按总参考词数归一化 |

这些是新模型输出前确定的研究门槛，不是业务 SLO。
OCR 固定采用经过核验的原生标注行顺序，不按某个模型输出重新排参考答案。
新版本同时修复单列表格分隔行；不猜测删除 YAML 或解释性文字。
格式/顺序差异仍会影响 CER，原始文本可用于解释，不另选对模型有利的评分。

## 专用相对三个通用的严格筛选

每个专用逐一对照全部三个通用，12 个比较均须成立：

- 同一独立质量样本上主指标严格更好；配对簇 bootstrap 10000 次，种子 20261015，
  单侧 95% 家族置信水平，12 比较 Bonferroni 修正，下界必须严格为正。
- 按 QA 文章、图像来源类、OCR 页、ASR 说话人分簇；QA 只有 6 篇文章，须披露精度范围。
- 同任务、同输入清单、同请求轨迹、同卡/功率上限、同观测 H 与启动摊销 A，
  专用显存比和端到端平均延时比均在 [0.5,2]，有效整卡功率严格更高。
- 三个固定种子的同负载成本对照分别检查；不拿饱和闭环的 J/request 替代能耗准入。

缺证据、失败/截断、功率积分缺覆盖或负载不稳定均不能通过。
这套筛选不会保证当前候选都符合要求，也不会预设优化器一定选择某类模型。

## 五项效用与固定参考

T/L/P/M/E 权重均 0.2，质量为硬门槛，不额外加分。
延时参考：QA 1000ms、图像 250ms、OCR 10000ms、ASR 3000ms；
显存预算 49140MiB，安全系数 1.110854；整卡功率参考 450W；启动摊销 A=3600s。
这些是统一研究尺度，不按候选自身表现分别缩放，也不截断到 [0,1]。
具体公式及运行时效用接入沿用 [效用规范](utility_specification.md)。
能耗采用完整部署的整卡功率积分：E_norm=(E_run/H+E_start/A)/450。
空卡差分仅作解释；不把每模型独立能耗相加；CPU 电耗不在本轮整卡指标内。
缺少合法整套部署证据时 U=null，不能把准备清单当作正式效用结果。
