# 当前固定部署的服务交互模型：可辨识性与最少测量

范围固定为 ASR2+G2n1+OCR1。这里设计新开发模型，不修改旧冻结 v2 或其零重拟合验证，也不声称该局部模型支持全模型池搜索。未读取独立验证或最终确认的结果。

## 先完成已预声明点，暂不增加 GPU 条件

已完成的两个开发点均为 seed51/H600、ASR1.8、背景各 .05，G2 ASR 份额分别为0和.25。父流程已预声明待执行的三个新开发点：ASR1.8/份额.125，ASR1.9/份额0与.125，背景仍各.05。此文不读取它们的运行结果。

先把训练、插值检查、负载迁移检查的角色保留：最初两点只供拟合；1.8/.125 检查分流响应弯曲，1.9 的配对点检查负载迁移和实际收益。完成这些检查前，不应因轻背景经验外推分数略正就继续扩展测量。若后来将这些新点并入拟合，它们就成为开发训练集，不能再称新模型独立验证。

## 最低复杂度模型及其不能解释的部分

第一版开发诊断可写成 `service(p,input)=frozen_input_service(p,input) × r_p(s)`，其中 `s` 是 ASR 给 G2 的份额。四条共同路径为 ASR/asr、G2/text、G2/image、OCR/ocr；每条路径 `r_p(s)=a_p+b_p*s`，共8参数。G2/asr 在 s=0 没有执行观测，仅在 .25 有一个倍率，因此只设常量1参数，不能凭空拟合斜率。合计9参数。

它在0..25%只做份额插值，不能把 ASR1.9 或背景 .01 称为训练域内插值。两条训练运行的路径服务总量误差按构造为0，但保留实测 Q/M/E 的 FIFO 训练效用误差仍分别为 +.027533、+.107538。故“每路径乘一个均值倍率”目前不足以重建尾延迟；偏差可能来自输入服务形状、到达时的并发状态、时间相关性或不同活动组合，不能归因给单一因素。

先比较逐输入服务残差与生成长度、ASR其他副本/G2活动重叠；同一输入重复观察和活动分组只用于诊断。需要预测的倍率不能取待预测 raw 的实际 overlap，否则引入信息泄漏。

## 已预声明三个新点能识别什么

若其残差支持线性局部响应，可尝试 `r_p(s,lambda)=a_p+b_p*s+c_p*(lambda-1.8)`。四条共同路径各3参数，G2/asr 也设3参数，共15参数。上述五个开发条件对 `[1,s,lambda-1.8]` 的设计矩阵秩为3；G2/asr 三个活动条件（1.8/.25、1.8/.125、1.9/.125）也为秩3，因此参数在聚合均值层面可辨识。

“设计矩阵满秩”仅表示有唯一局部线性解，不意味着模型正确、误差够小或有独立验证。尤其 G2/asr 三点恰好确定三参数，没有该路径的独立剩余条件来检验拟合。应保留正值约束、逐请求残差、运行级验证，先不加二次项和大量两两交互。若中点显示明显弯曲，应报告旧局部模型失败，再预声明增加的条件与模型形式。

现有五点均在背景 .05，无法识别背景负载系数。若要在此模型中新增 `d_p*(background-.05)`，总参数为20（五条路径各4参数）。最少再增加一个 G2 活动、背景不同的点，例如 ASR1.9/份额.125/背景各.01，可使所有路径的4列设计矩阵满秩；但仅一条新运行无法证明该模型的背景迁移正确。为了真实比较轻背景分流收益，还需同条件不分流控制，故最少是新背景下份额0/.125的开发配对两条。两条都不能复用61/62。

即便所有参数可辨识，也只能在观测条件的凸包附近声明局部开发适用范围，不能把少数不完整角点扩张成整个负载×份额×背景长方体，更不能推广到ASR1/3副本或其他通用模型。

## 若必须识别“活动并发导致服务变化”

仅改变份额会同时改变 ASR 两副本忙度、G2 ASR 混合比例和排队，因此对“ASR/G2成对活动”没有干净的因果识别。最小活动控制应固定所有模型常驻、输入集合、输入生成配置、暖机和到达安排，执行：ASR活动/G2仅背景，ASR常驻空闲/G2活动，双方活动三条件；并分别保留 OCR 活动状态。用同一个新开发种子配对，随机化执行顺序并记录GPU时钟、温度及功率，避免把电源或热状态误当计算竞争。若只有现有同时活动数据可以复用，它们的不同种子/输入/执行顺序必须列为限制。

不应立即拟合复杂干扰模型。只有控制实验显示所需结构后，才引入每路径的对方预测忙度等低维特征，并在按别名 FIFO 重放中自洽求解；多解、不收敛或超出训练范围必须返回未知。实际 overlap 不能成为线上预测输入。该类交互还会改变原搜索下界证明，旧独立 FIFO 的数学证书不能自动继承。

## 其他指标和数据隔离

六项权重、参考值和实际输出质量评分保持既定定义，不因负面结果改变权重或删掉图像背景任务。能耗若在固定4worker部署上拟合，仅能识别该部署的常量项和需求项，不能分开识别“基础功率”和“每worker功率”系数；旧全池功率参数不应重新解释成通过此局部测量得到。显存的开发采样最大值是局部经验值，不是硬件上界。

61/62 按原协议评价旧模型，失败也保留；如果查看后据此改模型，它们对新模型不再独立。新模型必须另命名、另冻结，使用81/82等新种子预声明新模型误差/排序验证。71/72/73继续作为尚未用于选路由或调参的最终确认保留；任何保留集一旦参与模型/候选选择，就需要换新确认种子。
