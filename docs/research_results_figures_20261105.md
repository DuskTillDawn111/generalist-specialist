## 目前最有依据的结果

**预算调度问题已修复，六次合成对照均提高效用。** 新版在旧版 EI 被挤出路由预算的 7/14 模型场景中，每次执行 7—9 个 EI 提案。两种规模最终 U 的中位数分别从 −0.383480257 提高到 −0.380109937、从 −0.380109937 提高到 −0.379667977。相同预算上限下，实际预测多 1—5 次；不能写成加速或计算量更少。

|合成模型数|种子|旧 U|新 U|新减旧|预测次数：旧→新|
|---|---:|---:|---:|---:|---:|
|7|11|−0.380109937|−0.377305615|0.002804321|36→39|
|7|29|−0.383480257|−0.380109937|0.003370320|38→39|
|7|47|−0.383683332|−0.380109937|0.003573395|34→39|
|14|11|−0.380109937|−0.379667977|0.000441959|49→53|
|14|29|−0.380109937|−0.379195224|0.000914713|50→53|
|14|47|−0.383683332|−0.380109937|0.003573395|48→53|

**真实冻结范围没有观察到组合算法的效用优势。** 共同计费初始化下，旧 BO–MADS、BO-only、MADS-only 的三个种子均停留在初始化最好值 U=−0.517921927；完整预测调用分别为 44/44/46、52/52/52、42/42/42。新版调度没有在这一真实预测器范围重跑。

**内层复用具有节省调用的证据，但认证状态必须同时报告。** 早期合成 FIFO 六次路由访问中，fresh exact 每种负载均需 72 次预测；shared exact 降至 8/7 次，shared budget 为 7/5 次。前两种策略均 6/6 次认证，预算策略为 0/6，不能把部分解画成精确最优。成本节省来自共享结构、界与调度的组合，不能全归因于部署池。

**总效用已经完成 v3 的结构调整，但不同场景的 U 不能混用。** 实测图采用四组等权的 v3：`U = −[Q + (T+L+P)/3 + M + E]/4`，对已有六次独立候选 episode 回顾性重评。三候选实测均值分别为 −0.514308311、−0.899424695、−3.182805256。合成凸排队场景和早期 FIFO 场景的目标定义/数据域不同，不用跨图 U 差值计算收益或预测误差。

## 出图规范与复现

每图均有矢量 **PDF/SVG** 和 **600 dpi PNG**。独立图按约 7.05 英寸双栏宽度设计，使用衬线字体、色盲友好配色、纹理与标记，英文坐标方便论文排版；中文解释见本文和图集导航。600 dpi 只针对 PNG，矢量文件不受分辨率限制。

三个优化种子使用原始点或中位数与最小—最大范围；两个实测历史使用原始点与均值。没有置信区间、显著性星号、曲线平滑或缺失点补造。范围展示样本波动，不代表统计泛化。

数据见 [CSV](../artifacts/research-figures-20261105/plot-data.csv) / [JSON](../artifacts/research-figures-20261105/plot-data.json)，共 530 条绘图记录；17 个源 JSON 的哈希见 [sources.json](../artifacts/research-figures-20261105/sources.json)。[绘图源码](../experiments/plot_research_results_20261105.py)仅读取结果，不导入优化器或预测器。
