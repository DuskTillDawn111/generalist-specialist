# 专用多副本分流研究推进记录

前轮研究完整归档，本轮使用独立目录 `artifacts/static-spillover-study-20261022/`。

## 研究设计

目标：七模型自由联合部署/副本/路由搜索自然选出目标专用至少两个副本，
同类任务正比例分给通用，且在双方可行时总效用优于最优不分流和其他强替代。
保持六项等权、质量/输入/参考、显存预算及已有原生模型配置不变。
结构仅为验收目标，不加入自由优化约束。

探索种子51；新负载独立验证预留61/62；最终独立确认预留71/72/73。
探索数据不能冒充独立验证；最终条件/候选在观察正式确认结果前冻结。
