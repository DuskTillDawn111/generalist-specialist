# 全历史统一重评分与正分流收益边界

本轮已把此前全部可用实测方案统一换权重，重新计算总效用和候选排名。最新耦合策略的303/304两次分流对照确实存在同一组正收益权重；此前旧批次的不可行结论不能外推为当前模型池无解。但目前仍没有新权重下的独立稳定正收益证据，也不能靠调权把最新耦合策略变成全部实测候选的冠军。

权威结果是 `artifacts/unified-weight-study-20261023/rescore-v3/` 和 `pair-scores-v2/`。较早版本保留作过程记录，最终读取这些版本。没有新增GPU运行，没有修改原始记录、冻结策略、原六项等权、稳定性或质量准入。

## 已完成的覆盖

- 原始 `run.json` 共133份，逐份保留路径及SHA256；112份原eligible且六项完整，全部在同样12组权重下重评分，共1344个数值效用。
- 其中73份原phase属于效果评估阶段，39份属于校准。校准也重评分，但仅列诊断排名；阶段标记不等于独立确认。
- 其余21份的缺失、失败或不合法状态保留UNKNOWN，共252个未知效用，不补零，不以缺测证明候选不可行。旧209的缺失能耗及未运行对照仍未补齐。
- 严格按负载、归一化/质量/能耗口径、模型池、请求样本与计划到达序列等分成37个可数值比较组，输出444份组内排名、2040个候选差值。没有跨负载合并总排名。
- 另按预声明路由识别67个文本分流/禁分流比较，全部在12组同样权重下计算804个差值。逐对保留是否同驻留、完整策略合同差异及比较类型；实际分流0次不自动定义为禁分流控制。

总效用为 `U=−(wQ·Q_norm+wT·T_norm+wL·L_norm+wP·P_norm+wM·M_norm+wE·E_norm)`。Q_norm是质量损失，六项均越小越好；Q的正权重奖励更高精度，不恢复绝对质量准入。收益为 `ΔU=U_spill−U_control`。

## 最新两次分流可以同权转正

冻结七模型池不变：Baichuan-Omni-1d5、MiniCPM-o-4_5-GPTQ（G2）、Qwen2.5-Omni-7B、Llama3-ChatQA-1.5-8B、siglip2-giant-opt-patch16-384、PP-OCRv6-medium、granite-speech-4.1-2b。

最新负载是text=1.85 rps、image/ocr/asr各0.01 rps，预热30秒、测量600秒。主驻留为两个文本专用副本、一个G2、一个OCR专用。coupled_spill与matched_no_spill使用相同驻留；完整策略合同差异限于分流开关及对应策略标记。两个分流臂实际分别向G2分流18、31个文本请求。

|评分权重Q/T/L/P/M/E|seed303 ΔU|seed304 ΔU|较小收益|
|---|---:|---:|---:|
|原六项等权|−0.030326781|−0.037268783|−0.037268783|
|15%/10%/20%/1%/4%/50%|+0.000750871|+0.000147767|+0.000147767|
|15%/10%/22%/1%/5%/47%|+0.000477121|+0.000508048|+0.000477121|

第三行是本轮更均衡的易读开发候选：保持质量15%、吞吐10%，将少量能耗偏好移给平均延迟及显存，使两次中的较小收益约为第二行的3.23倍。它是事后探索示例，不是已被业务需求确定的正式权重。

它并非只有一个精确点能正。在固定303/304测量向量上，权重仍非负和为1、且相对此示例的L1距离严格小于保守下界0.00215时，两次收益保持严格正。这由 `|g·δw|≤||g||∞·||δw||₁` 给出保守证书。该半径只描述**权重扰动**，不描述测量噪声、未来种子或新路由轨迹的稳定性；JSON内更长的浮点半径是近似展示，严格值以独立审计保存的有理数为准。

只把旧结果换权重不会改变已经发生的路由；若新权重进入算法，触发请求、分流数量和性能都可能改变，必须重新测量。

这些是完整连续权重域的LP结果，不是稀疏网格碰运气；保存精确有理可行见证及上界证书，并有独立精确LP交叉验证。下限/上限是敏感性条件，不是用户已指定的业务要求。若六项各保留至少2%，最新这两个固定配对就无法同时转正。

如果其他五项仍彼此等权，**仅降低P95权重**，seed303要求最终P95权重严格小于约0.1680107721%。一个实际重评示例把P的原始倍率降为0.001、其他五项倍率保持1，归一化后的P权重约0.019996%，两次分别得到+0.000272071、+0.002489897。这个变化非常大，不能把原始倍率0.001误读为最终P权重0.1%。

原因可以直接从成本差值看出：303的分流在Q/L/P上均损失，仅E改善；304平均延迟改善，但Q/P/E变差。两次需要相互平衡的权重，尤其压低P95；不能简单地说“能耗更好，所以都该分流”。P95权重降低不代表物理尾延迟改善。

## 怎样推进到可重复的正收益

本轮的具体结论是：调权方向有可行解，最有价值的开发候选是上面保留15%质量权重、P95为1%的例子；但它将47%放在能耗上，尾延迟偏好明显降低。是否适合作为最终总效用，应按研究所代表的质量、延迟和成本偏好解释，不能以“结果正”本身证明其合理。

下一轮应按下列顺序实施，避免在已经被支配的新coupled轨迹上继续调到过拟合：

1. 新建版本，同时冻结权重、部署候选及路由目标。候选包括当前领先的other_mixed及legacy各自的允许/禁止文本分流版本，双文本副本继续保留；原coupled对照留作参照。开启/关闭必须共用同一算法，仅改分流开关。
2. 让在线路由真正按同一新总效用选择，并对能耗预测提供可核对输入。other旧版本的事后E重评分不等于在线已能优化E；未知能耗不能当0。保持原质量与稳定性口径。
3. 修补当前预测的实际缺口：共享GPU同时执行对两专用服务时间的影响、未完成请求/后续到达对P95的影响，以及有完成反馈时的保守误差裕量。已有条件前缀P95预测多次为零，并未保证完整测量窗尾延迟改善；只降低权重无法消除这个偏差。
4. 优先测试other_mixed自身开/关分流的两个新开发配对，共4轮，先回答“当前最强混合部署的分流本身是否有益”。若两个配对都正且收益超过预先冻结的可辨识误差裕量，再用全新、未暴露种子做确认；原305–310属于旧门禁，不能绕过旧门禁挪用。开发收益不足时应按预设停止条件结束该版本。
5. 部署搜索与DFS必须共享新权重、同一冻结候选域和评价器，比较最优U、部署及路由是否一致，同时报告评价次数/耗时。现有4候选实测表重排只是有限候选验证，不是七模型全池物理最优证书；此前text-only的48→28次评价也不能代替完整混合负载验证。

高能耗权重还要报告窗后排空：现有E只计测量窗及按原规则摊销的启动/预热，不计窗后排空。新目标不能把“把工作推迟到未计能耗的排空阶段”误解为整批任务节能。保持原效用作主比较，同时列出排空时长/排空请求等诊断，若以后改变能耗边界应另立版本、统一重测。

这轮完成的是全历史同权重重评分和连续权重域证明；还没有把开发调权结果包装成独立稳定正收益。
