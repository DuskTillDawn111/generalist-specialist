# 去掉P95后的统一效用重评分

按用户“去掉P95，再试试”的要求，P权重严格设为0，总效用改为 `U₅=−(wQ·Q_norm+wT·T_norm+wL·L_norm+wM·M_norm+wE·E_norm)`，剩余五项权重和为1。Q仍表示质量损失。此次只对已有实测数据作新目标下的评分，不修改原始记录、旧报告、排队稳定性或质量准入，不新增GPU运行；P95实测值仍保留作诊断。

结果明确：最新303/304同驻留、同算法的允许/禁止分流对照，**五项等权就已经两次都正**，不再需要把精度、吞吐或显存权重压得很低。

|总效用设置|Q/T/L/P/M/E权重|seed303 ΔU|seed304 ΔU|
|---|---|---:|---:|
|原六项等权|各1/6|−0.030326781|−0.037268783|
|去P95，五项等权|20%/20%/20%/0/20%/20%|+0.000308827|+0.002537655|
|上一轮开发权重去P95并归一化|15/99、10/99、22/99、0、5/99、47/99|+0.002335524|+0.002900058|

第三行即约15.1515%/10.1010%/22.2222%/0/5.0505%/47.4747%，严格计算使用表中分数。它保持其余五项的相对偏好，相比之前含1%P95的15%/10%/22%/1%/5%/47%，较小配对收益由0.000477121提高到0.002335524，约4.90倍。这只是评价目标改变后对相同轨迹的重评分，不表示物理性能改善了4.90倍。

最新实验仍是text1.85 rps、image/ocr/asr各0.01 rps；双文本专用副本、一个G2通用、一个OCR专用；预热30秒、测量600秒。分流臂两个种子实际分流18、31个文本请求。

五项等权时的收益来源也能逐项核对：303是能耗改善抵消质量和平均延迟损失，304是平均延迟改善抵消质量和能耗损失；两次T/M收益均为0。删除P95后，原尾延迟损失不再进入总效用。

## 全部候选同时重排

五项等权下，最新四候选排序如下，U越大越好：

|排名|具体方案|seed303 U₅|seed304 U₅|两次平均U₅|
|---:|---|---:|---:|---:|
|1|legacy_latency：双文本专用+G2+OCR，旧延迟队列路由|−0.627733585|−0.622057452|−0.624895519|
|2|coupled_spill：同驻留，新耦合效用分流|−0.631219520|−0.638695655|−0.634957587|
|3|other_mixed：多一个图像专用，旧refinement/global_incremental路由|−0.632658090|−0.639074399|−0.635866245|
|4|matched_no_spill：同一新耦合算法，关闭文本向G2分流|−0.631528347|−0.641233310|−0.636380829|

所以删除P95后，coupled从原等权的第四升到第二，也超过other_mixed，但仍没有超过legacy。使用第三行能耗偏好更高的权重时，排序为other、legacy、coupled、matched；完整数值在analysis.json中。

seed304中legacy在剩余Q/T/L/E四项仍严格好于coupled，M相等。因此P=0也无法通过非负权重让coupled在两个种子同时严格击败所有其他候选。有限候选中的领先与某一算法自身的分流收益需要分别评价。

## 正收益范围与历史压力检验

在剩余五项的连续权重域上，分别求“两个配对中较小收益的最大值”；P始终固定为0。五项权重下限0/1%/2%/5%/10%/20%，单项上限100%/50%，12个范围全部存在共同正收益。五项各至少20%时只有五项等权这一解，也仍然为正。

这修正了上一轮“六项各至少2%时最新两次不能同时正”的适用范围：该障碍依赖P95必须保留正权重；P固定0后不再成立。下限是数学敏感性条件，不是额外业务要求。

但删除P95无法救回所有历史策略。以下两组新权重的正收益次数一致：

各行保留自己的负载、策略版本和证据阶段，未跨负载合并效用排名；同驻留不同策略的比较不提升为严格分流消融。旧205在剩余指标上仍被控制弱支配，所以“删除P95后所有旧配对一起转正”也不可能。

本次完整覆盖133份原始记录：112份可重评分，其中73份属于原效果评估phase、39份校准仅作诊断；其余21份保留UNKNOWN。旧12组权重去P归一后去重为9组，另加新五项目标的7组不同maximin见证，共16组统一评分：1792个数值效用、336个未知效用、592份兼容组排名、2720个综合差值及1072个明确分流/禁分流差值。所有方案都采用同一组权重比较。

## 当前判断

如果研究目标正式去掉P95，下一轮以**五项等权**作为清楚的主目标已有开发依据：精度、吞吐、平均延迟、显存、能耗都保留20%，最新两次自身对照收益为正。上一轮去P后的能耗偏好权重可作敏感性条件，无须直接当主目标。

下一轮应把五项目标同时接入部署搜索和在线路由，使用同算法、同驻留的分流开关配对及新未暴露种子验证。现有轨迹中的P95较差仍是事实，删除其效用项不会改变该指标；原稳定性设置继续保持。旧305–310门禁不因事后改目标而失效。

已有数据只支持“新目标下最新两个开发配对都正”，尚不支持跨种子稳定性确认、全池最优，或新目标驱动路由后的收益。DFS也需要在相同新目标与冻结候选域下重新核对，当前重排不替代那项验证。
