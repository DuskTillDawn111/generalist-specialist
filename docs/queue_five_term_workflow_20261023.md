# 五项等权目标的前瞻在线实验

用户在去P95事后重评分后授权实际执行。本阶段固定Q/T/L/M/E各0.2，P=0；P95继续记录作诊断。新策略的每次在线决策、实际SystemConfig、资源身份和最终实测评价均绑定此目标，不沿用旧六项等权进行路由后再事后改分数。

新实现隔离在 `tools/queue_five_term_20261023/`，原coupled/refined包、旧收据和305–310旧保留种子均不修改。预声明文件为 `artifacts/queue-five-term-study-20261023/prospective-design-v1.json`，开发执行包为 `native-development-packet-v1/experiment-packet.json`。

冻结七模型来源池不变；本次实际驻留是text两个专用副本、G2通用一个副本、OCR专用一个副本。负载text1.85 rps，image/asr/ocr各0.01 rps，Poisson到达，预热30秒、测量600秒、排空上限300秒。原排队稳定性、rho=0.8先验、质量无绝对准入、板卡测量窗能耗及启动摊销规则均保持。

开发域包含4个角色，每个使用新种子401/402：

|角色|路由|文本向通用分流|
|---|---|---|
|coupled_spill|新五项耦合效用路由|允许|
|matched_no_spill|同一新五项路由|关闭|
|legacy_latency|原延迟队列启发式基线|允许|
|legacy_no_spill|相同延迟队列评分和guard|仅关闭候选文本通用路径|

各配对401先开后关、402先关后开。先完成新主策略的4轮，再完成基线4轮。legacy关闭分流时不切换为另一种quality_aware策略；基线只优化自身延迟启发式，不能称完整五项在线优化器。另一图像专用驻留方案的旧结果仅作历史参考，不与新种子U混排。

主策略固定使用mean+p90、效用触发margin=0、漂移冷却30秒。若完整混合负载CPU预测域仍缺证据，按此前声明使用此默认；text-only诊断的winner不能代替完整混合负载选择。新CPU搜索在不同种子413/414重新执行24个策略的事件模拟，比较独立DFS与仅使用已证明策略等价的去重搜索；未知保留未知。

只有8轮证据全部完整有效、新主策略两个配对均实际分流且ΔU>0.0001，才启动固定主策略的6组独立确认（421–426，每组开/关各一轮）。0.0001是预声明探索实用下限，不是测量噪声置信界。不会因为legacy结果更好而替换确认主策略。确认终点要求6组都完整有效、实际分流并且ΔU>0，同时报告单组收益和不确定性；门禁失败则完成开发比较并明确停止确认。

执行串行占用GPU，不自动重试失败。每个run.json只写一次；progress.json是可更新状态视图。每轮结束生成中期分析，完整开发结束形成analysis.json和terminal.json。新包源码在执行包中冻结，运行后只能在包外追加审计工具，不能改变已绑定代码。

本阶段要回答的是新目标驱动的路由是否真实取得可重复分流收益，以及有限策略域的算法/DFS效率。单一驻留域的结果不能证明七模型全池最优；查表排名不能作为减少GPU实测次数的算法加速证据。若完整CPU仍UNKNOWN，应单独报告资源证据缺口及text-only效率，不能把空winner相等说成最优一致。
