# 共享 GPU 耦合效用实验推进记录

本阶段接续已完成的六项权重探索，使用独立目录，不改写上一阶段冻结代码、原始测量或 seed209 的未知终点。目标是检验新部署/路由能否改善实际性能；不是通过事后调整权重保证正收益。

## 固定的评价与证据边界

- 继续使用七模型配置池、六项等权 Q/T/L/P/M/E、原稳定性和质量计分，不恢复绝对质量准入。
- 实测六项总效用为最终比较依据；在线决策只能使用当时已观察到的请求、队列和历史校准证据。实际答案、未来请求和未来服务时间不进入策略。
- 显式模拟共享 GPU 上所有活动请求的服务变化与一次整板功率积分。历史条件相关性不能自动当作动态竞争的因果模型；未覆盖状态必须标记未知，并采用禁止分流回退。
- 在线前缀预测不等于完整到达窗的精确总效用。实测峰值显存不能仅因驻留相同就视为相同；必须保留其预测不确定性。
- 原测量窗 E 口径保持不变；新增整批请求排空能耗诊断，单独报告，不替代原指标。
- 旧205–209只作已见诊断，不用于新校准。新校准、开发和确认使用明确分开的新种子、冻结代码和收据。

## 执行阶段

1. 在 `tools/queue_coupled_utility_20261023/` 实现共享事件引擎、资源证据适配、因果反馈和可重放原生执行。
2. 用聚焦测试确认竞争反馈、未知回退、指标口径及无未来信息；核查旧冻结文件哈希。
3. 完成必要的新 GPU 校准，检查可识别的服务/功率支持域；校准不支持的状态不外推成确定收益。
4. 在支持域内比较新路由、同驻留禁止分流、旧路由及明确部署对照；运行有限候选搜索与 DFS，报告目标、候选域、相同最优解及实际搜索成本。
5. 冻结新独立实验，串行执行配对测量，审计全部终点与缺失项，报告收益、失败及其范围。

进度和实际设计以本阶段独立 artifacts 目录中的机器可读记录为准。只有完成新测量与审计后，才对收益作结论。

正式使用 `artifacts/queue-coupled-study-20261023/controlled-resource-fit-v2/resources.json`，SHA256 为 `6b183f8f76a881dbc19fd99d8c4c785d5245674212a872f5806ec365ddeb8ea1`。53 项聚焦测试通过后冻结新执行包，SHA256 为 `7a221312df073ce9405c2ab64b601ef5686bcc1b3c08be1fa85d50608cd0b949`。冻结后不修改新包 Python 源码。

正式开发负载仍为 text 1.85 请求/秒，image、ASR、OCR 各 0.01 请求/秒；每次 30 秒预热、600 秒测量、最多 300 秒排空。seed303 按以下顺序运行，seed304 反序运行：

1. `coupled_spill`：文本专用两个副本、通用 G2 一个副本、OCR 专用一个副本，使用新耦合效用路由。

CPU 原混合负载域尚缺受控背景活动功率证据，所有未知候选均保留 UNKNOWN，未据此选出赢家。因此原生运行遵循事先声明的默认新策略：mean+p90 情景、零效用余量、30 秒漂移冷却、text/8 的分流令牌速率，以及 32 个待处理请求的确定性预测预算。完整队列不截断；超过预测预算时跳过预测并回退专用。

只在两个开发配对均完整有效、均真实发生新策略分流且各自总效用差值为正时，执行预留 seed305–310 的六个独立确认配对。否则记录负结果或未观察到机制；基础设施失败按预声明停止且不重试。CPU 的有限数值域 DFS、已测原生候选表 DFS，与七模型配置池物理全局最优的证明是不同结论。

## CPU v2 已完成结果

独立审计 `cpu-search-v2-independent-audit-v1/audit.json` 为 `PASS_WITH_SCOPE_LIMITATIONS`。原完整混合负载 24 个候选、48 个候选/种子组合均缺背景活动功率证据；两个搜索均未识别赢家。空赢家和空并列集合一致是空结果一致，不能作为最优性证明。

text-only 机制诊断的 24 个候选均可计算，唯一数值赢家为允许分流、mean+p90、margin=0、cooldown=30s，平均条件代理效用为 -1.3340921916805695；seed313/314 分别分流 66/59 次。DFS 与优化搜索的全部运行字段、效用和完整并列集合一致。

两套算法真实独立调用模拟，未缓存已经计算的目标值。DFS 48 次、优化 28 次，减少 41.67%，完全来自事先证明的无分流控制策略符号等价；严格界剪枝为零。text-only 观察耗时 312.343 秒与 180.953 秒，约 1.7261 倍，仅为一次顺序、非隔离计时，不能声称为严格冷启动性能证明。text-only 的有限代理域证书不包含原混合负载、完整物理稳定性或七模型配置池全局最优。
