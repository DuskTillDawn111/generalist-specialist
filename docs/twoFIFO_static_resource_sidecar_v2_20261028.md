# Native v3 nominal structure sidecar v2

`twoFIFO_static_resource_sidecar_v2.extract(training_review, static_inventory)`
uses the actual `twoFIFO_composable_macros_v3` extractor and native review v3.
That extractor checks the full native source receipts and rederives the original
complete native review. The sidecar checks the actual v3 review/raw/plan schemas
and attempt/execution/block identities, then verifies the declared static worker
spec against both captured context and READY. No older document is relabeled or
passed through the v1 sidecar. Existing audited sources remain unchanged.

The source-bound seven-projection feature and `pair_state` helpers are reused
without fitting. Every measured request and macro remains in the output. The
whole attempt's processed events include all eighteen priming requests; their
complete processed event records are retained separately as history, never as
measured response labels. The descriptor catalog preserves every supported
actual language BEGIN, including priming. Missing shapes and unbound owners have
an explicit unsupported catalog.

The exact current BEGIN becomes available only at its collector processing
clock. Changing a later BEGIN shape cannot change earlier pieces. Future
macro shape, later decode, END, worker output and completed exposure cannot fill
missing current shape. Every causal path piece and every peer remain present,
with exact K + U = N and exposure denominators. Future or duplicate visible
peers fail the pure transform's input contract. Unsupported entry/OCR/tails and
unobserved language shapes stay UNKNOWN; all-peer aggregates remain unknown
when any pair is unsupported.

The features describe declared dense-equivalent FLOPs and logical operand bytes
of q/k/v/o/gate/up/down projections. They do not measure physical traffic, runtime
quantized storage, attention/KV work, SM service, cache reuse or compute/memory
classification. The complementary service multiplier is explicitly unknown.
Native training source review is rederived; runtime loaded-operator and physical
resource identity receive no new authentication. No rate changes, numerical
fit, provider, final utility qualification or validation are produced.

Nine CPU tests use the real v3 whole-attempt macro partition with synthetic
records. They cover schema rejection, full rows and priming history, processed
BEGIN boundaries, missing shape without backfill, unknown peers, future peer
shape invariance, zero-peer exposure, malformed peer cutoffs and the mandatory
real native extraction entry. The frozen v3 collector has no reverse import.

The first accepted native v3 shard was separately extracted using its actual
rederived review and the existing source-bound topology inventory. Its artifact
retains 46 measured requests, 266 macros, 994 priming history events and 365
supported language BEGIN descriptors. Known projection pairs cover approximately
35.0034% of visible peer exposure; all other pair exposure remains UNKNOWN.
This is one-shard structural diagnosis, not a fitted or qualified law.
