# 当前配置证据下的六项权重探索

本分析由2026-10-23用户提出“在当前配置池下合理调权以稳定正收益”后启动。它是已见数据后的探索，不是预注册独立验证；不修改原六项等权实验、冻结策略、稳定性、能耗积分规则或原始记录。

## 明确比较问题

总效用保持 `U=-sum(w_j * normalized_cost_j)`，所有权重非负且和为1。定义每个完整配对的六维收益向量为 `g=control_cost-spill_cost`，则分流收益为 `ΔU=g·w`。只调偏好，不改变任何实测性能。

本轮独立证据只有205/206/207/208四个完整配对；209分流E/U未知、控制未执行。四对结果不能替代原五对终点。开发证据另有两个负载各四条件、203/204两个种子，其作用为探索部署/策略权重区域，不能冒充新的独立验证。

“稳定”至少需要分开报告：

- 四个已知配对是否存在同一权重均为正：最大化最差配对收益。
- 四个已知配对的均值能否转正：均值最优和离原等权最近的可行权重。
- 已测开发域中某部署/策略能否在两个种子上都优于其他候选：仅证明有限已测域，不证明七模型池物理全局最优。
- 对新的目标重新优化部署与路由后能否获得可重复收益：需要新冻结实验，本轮事后评分不能回答。

## 搜索范围与可复核性

首先分析完整六维权重单纯形，不事先排除任何非负权重；然后报告对称的权重下限/上限族作为设计敏感性，不把任意对称约束宣布为业务上“合理”。原等权作为参考点。

对每个范围分别求最差收益最大值、均值最大值以及离原等权最近的均值不负/正裕量方案，输出所有权重、逐配对ΔU、求解状态和约束残差。正裕量使用明确标记的探索阈值，不与统计显著性混淆。逐项支配关系与解析不等式优先于数值求解器的成功标志。

对于仅通过单个异常大收益拉正均值、需要近乎舍弃质量或延迟、或仅在开发数据获益的权重，报告其具体代价与证据范围，不称为稳定优越方案。新权重若依赖能耗收益，必须检查当前搜索/路由能否实际估计能耗；事后E评分不等于在线算法已经按E优化。

## 已核实的必要事实

seed205在Q/T/M上与控制相同，但分流的L/P/E三项都更差。因此任何非负权重都无法使该固定配对的分流收益严格为正。这是全部权重空间上的支配证书，不依赖某个网格或任意“合理范围”。

四个完整配对的平均六维收益为：

|项|control成本减spill成本的配对均值|
|---|---:|
|Q|-0.0015514184397163178|
|T|-0.04115647626709573|
|L|-9.455979766149314|
|P|-28.262037896653545|
|M|-0.0026335875254375474|
|E|+0.01693165119826809|

只有E的配对平均为正。若其他五项保持彼此等权而只提高E，均值转正需E权重大于约99.7763%；这不能推导出每个配对都转正。允许其他项独立变化时需另报完整可行区域，不能把此一维阈值冒充所有权重调整的必要条件。

## 已完成的全权重搜索

外部工具 `tools/queue_refined_full_weight_exploration_20261023.py` 已对实际数据运行完成，输出为 `artifacts/queue-refined-study-20261023/full-weight-exploration-v1/`。搜索包括完整单纯形，以及每项下限0/2%/5%/10%、上限100%/50%/35%的12个对称范围；每个范围分别求最差收益、平均收益和距离原等权最近的均值达标解。另对两个开发负载的4个候选、各自两个种子与其余3个候选的6项对比检查稳健可行性。8项针对性测试通过。

四个完整独立配对上的全域最优最差收益仍为 `-0.00023909569008495737`。精确最优权重为Q约92.3716%、E约7.6284%，其他项0；该权重只是不可行性证书的端点，不是推荐配置。独立审查给出完全相等的有理数原始/对偶上下界，因此“最差收益仍负”不只是求解器状态。seed206与207、206与208也分别存在非负组合支配证书，排除它们同时严格正收益。

若只追求四对平均值，全域最优为E=100%，平均ΔU=+0.01693165119826809，但仅2/4对为正。离原等权最近、使均值达到探索裕量1e-6的一组权重约为Q/T/M各16.6667%、E49.9904%、L0.0095843%、P0%；也仅2/4对为正，最差约-0.00156685。这两个数值例均不能作为稳定收益权重。

逐次删除一整次配对的诊断保留主分析不变：去掉208后，205/206/207的平均收益向量在所有项上均非正，任何非负权重都不能使该子集均值严格正。因此四对平均转正依赖208的能耗改善，不是跨种子一致改善。全部5对的完整效用统计仍UNKNOWN；已知4对已经不满足稳定正收益的必要条件。

## 当前配置候选的开发证据

1.85负载下，校准分流在开发203/204两个种子都正的权重区间确实存在。seed203要求 `wE > 13.836544552*wL + 21.863256149*wP`；若L/P各至少5%，即使其余权重尽量偏向有利方向，也无法使该次配对转正。该条件只针对旧实测轨迹重评分，不是未来路由保证。

例如Q/T/L/P/M/E=15%/10%/1%/1%/23%/50%，开发203/204收益分别为+0.0004592294、+0.0030134762。但同一权重重评分独立205/206/207/208则为-0.0019704184、-0.0007963596、-0.0004806920、-1.4914262762，四次全负。这是“开发集调权能正”不等于“独立稳定获益”的具体反例，不是建议采用该组权重。

1.89的校准分流、两个负载的旧延迟分流和两个负载的另一混合部署，均没有同时超过同驻留禁止分流控制的两种子严格正收益权重。另一部署还改变了驻留与图像路径，只可解释为部署加路由的综合比较。有限域中1.89的禁止分流可在部分受限权重范围下两种子都超过其他3候选，这不构成正分流收益。

## 能耗口径与后续目标

E只覆盖600秒测量窗能耗，以及按3600秒摊销的启动/预热板卡能耗，不计CPU或窗后排空。seed208分流仅943/1130个请求在窗内完成，187个在窗后排空完成，排空129.5935秒；控制窗内1128个、窗后2个，排空0.2340秒。因而该次E较小只表示原计量口径下较小，不能断言整批同任务更节能。抬高E同时压低T/L/P，可能偏好把工作移到未计E的排空段；现有观察不证明该激励就是实际行为原因。

当前conservative路由使用Q/L代理，global_incremental使用Q/L/P及可选E，正式构建未提供E率，CPU筛选使用QTLP。后验六项重评分没有变成在线六项优化。后续若研究新权重，应同时冻结目标及对应的部署/路由搜索；能耗偏好较高时还需可靠的E证据，不能把未知当0。

因此目前没有可推荐且被独立数据支持的“调权后稳定正分流”配置。该结论适用于当前已测策略与有限候选，不排除相同模型池下通过新的部署/路由获得物理改善，也不是整个七模型池的不可行性证明。
