# Module32E GPU 工程预检协议（预先冻结）

只执行一次 E0_DYNAMIC，600 秒工程窗口；使用 Module32B 已保存的 Dynamic 开发输入和到达轨迹。该选择延续原路由器600秒风险预算，不筛选种子、不比较效用、不做独立复现。模型池、六任务QPS、权重、单副本驻留、质量准入、B3预算和路由参数保持原定义。300秒真实六任务S-only调理使用32D既有工程轨迹，30秒warmup，原60秒完整排空。所有模型每次从相同本地权重重新加载；本轮仅一臂，不能证明配对热状态可比。

原温控要求：空GPU启动前温度≤38°C，连续3次样本，间隔2秒，最多300秒；驻留预热后≤40°C，连续3次样本，最多180秒。前后各2秒驻留空闲记录，实际峰值与safe_factor驻留预算核验。原配对平均温差5°C、SM均频相对差15%在今后的配对验证仍适用，本轮无配对，不宣称通过该项。

不改变功率、频率、风扇或推理设置。0.5秒遥测记录实际SM/显存频率、温度、Pstate、功率和450W功率上限、风扇、clock event reasons和硬/软件热降频标志，结合请求执行区间解释，不根据平均温度推断降频。NVML/进程采样、deepcopy、JSON序列化及fsync不持有控制state_lock。10秒durable journal保留完整终态请求，原控制检查perf_counter墙钟计时及发布计时均保留，任何一次≥10ms立即停止下一请求准入，保存样本及完整planned cohort，不重试、不删异常点。在线路由完整lock+projection+decide+enqueue的P95≤1ms。

父进程与全部worker继承Landlock/seccomp，并由独立launcher先安装Python写入审计再运行原backend，所有缓存与临时文件在Module32E。CPU后完整SHA清单作为紧邻GPU启动前的历史输入清单，GPU结束再重新读取全部文件复算SHA；测量期间不运行全盘哈希，避免主动IO竞争。worker正常退出时保存全部被阻止的写入尝试；任何非预期写入尝试均令预检失败。设备和/dev/shm仅供CUDA/IPC，不是科学输出目录。

工程验收要求完整六任务请求、原时钟口径和稳定性判据、质量支持路径及closed-set输出、预算、线程/worker清洁退出、PID释放、因果状态与策略逐字段回放一致。正式U不调用也不计算；所有U=NULL。控制超限立即停止，不开启新的GPU运行或长窗口。
